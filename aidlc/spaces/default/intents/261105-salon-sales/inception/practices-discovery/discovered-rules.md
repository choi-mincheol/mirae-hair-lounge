# 발견된 강제 규칙

> 사람이 직접 밝힌 강제 규칙만 담았습니다. 처음 두 규칙은 사용자가 `README.md`의 `## Mandated` 절에 직접 적은 문장을 그대로 옮겼고, 세 번째 규칙은 인터뷰 Q1에서 사용자가 밝힌 조건("작업 진행하면서 커밋/푸쉬 진행할건지 나에게 물어본다.")을 규칙 형태로 적었습니다. 추측으로 만든 규칙은 없습니다.

## Mandated

- ALWAYS 서버는 `127.0.0.1`에만 바인드한다.
- ALWAYS 빌드 게이트는 `./gradlew build` 하나로 유지하고, 새 테스트도 이 빌드 안에서 돌게 한다.
- ALWAYS 커밋이나 푸시 전에 사용자에게 진행 여부를 물어보고, 동의를 받은 뒤에만 실행한다.

## Forbidden

None.
